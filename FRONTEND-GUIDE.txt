===============================================
  FREST ADMIN - FRONTEND ONLY MODE
===============================================

 FULLY WORKING WITHOUT BACKEND!

This application uses MOCK DATA to simulate a real backend.
All features work perfectly for frontend development and demo purposes.

-----------------------------------------------
 QUICK START
-----------------------------------------------

1. Install dependencies:
   npm install

2. Start development server:
   npm start

3. Open in browser:
   http://localhost:3000

-----------------------------------------------
 WHAT WORKS
-----------------------------------------------

 Authentication (Login/Register/Logout)
   - Login with ANY email & password
   - Registration creates mock users
   - Session management with localStorage

 All Dashboards
   - Analytics Dashboard
   - E-commerce Dashboard
   - Logistics Dashboard  
   - Academy Dashboard
   - All with REAL-LOOKING data

 User Management
   - View user list
   - Add/Edit/Delete users
   - Filter and search

 Product Management
   - Product listing
   - Add/Edit/Delete products
   - Categories and filters

 Order Management
   - Order listing
   - Status updates
   - Customer tracking

 All UI Components
   - Cards, Forms, Tables
   - Charts (placeholders)
   - UI Elements
   - Navigation

-----------------------------------------------
 HOW IT WORKS
-----------------------------------------------

Mock API System:
- Located in: src/services/mockApi.js
- Simulates network delay (300ms)
- Stores data in memory
- Persists during session

Data Storage:
- Users, Products, Orders stored in memory
- Authentication state in localStorage
- Changes lost on page refresh (can be enhanced)

-----------------------------------------------
 CUSTOMIZATION
-----------------------------------------------

1. Add More Mock Data:
   Edit: src/services/mockApi.js
   - usersData[] 
   - productsData[]
   - ordersData[]

2. Change Mock Delay:
   const MOCK_DELAY = 300; (in mockApi.js)

3. Add New Features:
   - Create new page in src/pages/
   - Add route in src/routes.jsx
   - Add nav link in src/components/Sidebar.jsx

-----------------------------------------------
 SWITCH TO REAL BACKEND
-----------------------------------------------

When your backend is ready:

1. Set environment variable:
   REACT_APP_USE_MOCK_API=false

2. Update API URL in .env:
   REACT_APP_API_URL=https://your-api.com/api

3. The app will automatically use real API!
